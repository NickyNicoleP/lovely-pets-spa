## 🚀 LOS 6 PASOS MÁS IMPORTANTES

### 1️⃣ DESCARGAR (5 minutos)
```
✓ OBS Studio: https://obsproject.com
✓ Google Authenticator: Play Store / App Store
```

### 2️⃣ PREPARAR BD (3 minutos)
```
✓ phpMyAdmin: http://localhost/phpmyadmin
✓ Copiar: backend/prepare_demo.sql
✓ Ejecutar en SQL tab
```

### 3️⃣ INICIAR SERVIDORES (2 minutos)
```
Terminal 1: cd backend && npm start
Terminal 2: cd frontend && npm run dev
```

### 4️⃣ CONFIGURAR OBS (3 minutos)
```
✓ Nueva escena
✓ Captura de ventana (navegador)
✓ Resolución 1920x1080, 30fps
✓ Micrófono probado
```

### 5️⃣ GRABAR (12 minutos)
```
✓ Seguir SCRIPT_DETALLADO_VIDEO.md
✓ Consultar REFERENCIA_RAPIDA.txt mientras grabas
✓ Escenas: Registro → Bloqueo → 2FA → Auditoría → Cambio Pass → Resumen
```

### 6️⃣ SUBIR (5 minutos)
```
✓ YouTube.com → Crear → Subir video
✓ Título: "Sistema de Autenticación Pet Spa - Demostración de Seguridad"
✓ Descripción: [Ver INICIO_RAPIDO_VIDEO.md]
```
