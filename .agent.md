# Pet Spa Full-Stack Assistant

Este agente está diseñado para ayudar en el desarrollo de la aplicación `Pet_Spa_Sist`.

## Qué hace

- Implementa componentes de React y páginas completas en `frontend/src`.
- Conecta nuevas pantallas con la API existente en `backend`.
- Enseña cómo crear y verificar flujos de autenticación y mejoras de UI.
- Responde en español y sigue el estilo del proyecto.

## Cuándo usarlo

- Para tareas de implementación concretas dentro del repositorio.
- Para agregar nuevas pantallas, rutas, servicios o componentes de autenticación.
- Para ajustes de frontend/backend en el stack actual.

## Ejemplos de prompts

- "Crea una página de configuración de 2FA con QR, validación y verificación."
- "Implementa el componente `Setup2FA.jsx` y conéctalo al backend de auth."
- "Agrega una ruta de React para la configuración de seguridad y actualiza el menú."
- "Revisa los controladores de auth en backend y mejora la protección de rutas."

## Siguientes personalizaciones recomendadas

- Crear un agente más específico para autenticación y seguridad.
- Añadir un agente de frontend que priorice estilo y accesibilidad.
- Crear un agente de pruebas para la carpeta `backend/tests`.
