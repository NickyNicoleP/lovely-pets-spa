## 🎯 CASOS DE USO

### Caso 1: Nuevo Usuario
1. Accede a `/pawspa-login`
2. Ve página hermosa
3. Click en "Regístrate aquí"
4. Completa registro

### Caso 2: Usuario Retornante
1. Accede a `/pawspa-login`
2. Email está pre-llenado (Remember Me)
3. Ingresa contraseña
4. Login inmediato

### Caso 3: Olvida Contraseña
1. Click en "¿Olvidaste tu contraseña?"
2. Ingresa email
3. Recibe código
4. Ingresa código + nueva contraseña
5. Login exitoso

### Caso 4: 2FA Requerido
1. Login con usuario 2FA
2. Pantalla 2FA aparece
3. Ingresa código del autenticador
4. Acceso otorgado
